# DeftOS — Short Description

DeftOS is a lean, branded Arch Linux distribution built on CachyOS. It runs KDE Plasma 6 on a Linux 7.2.10 kernel, installs through Calamares without hardware selection screens, and includes Snapper snapshots and an LTS fallback kernel for safe recovery.

---

**One-line summary:** A fast, minimal KDE Plasma 6 distro on CachyOS, with a simple installer and built-in rollback.

**Key points:**
- KDE Plasma 6 desktop
- Linux 7.2.10 kernel
- Minimal base package set
- Calamares installer, no CPU/GPU selection
- Snapper snapshots and LTS kernel fallback
- DeftOS branding package
